# Contactes - Nova App

App web responsive per PC i iPhone.

## Funcions

- Importar registres des d'un `.xlsx`
- Exportar tots els registres a `.xlsx`
- Afegir nou contacte
- Buscar per nom
- Guardar coordenades GPS manualment o amb la geolocalitzacio del dispositiu
- Obrir la posicio a Maps
- Calcular edat, temps transcorregut i dies que falten per la propera data
- Mostrar avisos de dates properes

## Obrir al PC

Fes doble clic a [abrir-app.bat](C:/Users/Maso/Desktop/LLuis%20IA/contactos-app-nueva/abrir-app.bat)

Aquesta opcio arrenca un servidor local i obre l'app a `http://127.0.0.1:8765`, que va millor per al mode tipus app.

## Per usar-la a iPhone

1. Cal publicar aquesta carpeta com a web.
2. Obrir-la a Safari.
3. Fer `Compartir > Afegir a pantalla d'inici`.

Nota: els avisos actuals es mostren quan obres l'app. Per avisos push reals fora de l'app caldria una versio publicada amb notificacions web completes.
